## How I build

**[Agentic Harness](https://github.com/JessAutomating/agentic-harness)** is the open-source operating method I wrap around coding agents to ship and operate production software. It keeps context durable, decisions explicit, delegation disciplined, and every change grounded in builds, tests, evaluations, browser checks, and review evidence, not the model alone.

## Open source

- **[Local Transcriber](https://github.com/JessAutomating/local-transcriber)** - Any-length transcription on your own machine. No cloud, no file-size cap, no paywall. Ships as a Dockerized FastAPI service with CPU and GPU images that also scales on Kubernetes, with workers that autoscale from zero on queue depth.
- **[Self-Hosted n8n on Kubernetes](https://github.com/JessAutomating/n8n-selfhost-k8s)** - Run n8n on your own machines instead of renting it. Docker Compose on one host, or Kubernetes in queue mode with autoscaling workers backed by Redis and Postgres, plus a local-AI support triage workflow where no data leaves the box.
- **[Lead Engine on Kubernetes](https://github.com/JessAutomating/lead-engine-k8s)** - A scheduled scrape, enrich, score, write, and notify pipeline packaged for Docker and Kubernetes, with a safe zero-spend dry run.

## Systems in production

- **A medical practice's back office** - Bank sync, receipt capture, daily briefings, and automated monthly reports.
- **A coaching growth stack** - An AI email assistant, a booking agent, and a content engine that turns one upload into many channels.
- **A client-memory system for coaches** - Scattered notes become organized client timelines, with AI that cites its sources and never invents.
- **A self-running operations mesh** - Self-hosted n8n with local models: email triage, a billing sentinel, and a support draft assistant that never auto-sends.
- **A safety-gated model evaluation** - A repeatable GO or NO-GO evaluation for choosing a local model, with blind judging and a pre-registered safety auto-reject.

Client work stays anonymous and private source stays private. The repositories above are my own and open.
